# Run in GitHub Codespaces

This branch includes a Codespaces configuration for the Operations module and
the existing Rocket Overlay Studio.

## Start the Codespace

1. Open the repository on GitHub.
2. Select the branch `agent/operations-foundation`.
3. Select **Code → Codespaces → Create codespace on
   agent/operations-foundation**.
4. Wait for the automatic dependency installation to finish.
5. In the Codespaces terminal, run:

   ```bash
   python app.py
   ```

Codespaces forwards port `5000` and opens the application in a browser.

## Open each module

- Operations: append `/operations/` to the forwarded URL.
- Rocket Overlay Studio: open the forwarded URL without an additional path.

Example:

```text
https://<codespace-name>-5000.app.github.dev/operations/
```

The exact hostname is generated by GitHub. You can also open it from the
**Ports** tab by selecting **Open in Browser** beside port `5000`.

## Stop the server

Return to the terminal and press `Ctrl+C`.

## Data

The Operations SQLite database is created at:

```text
workspace/operations.db
```

It remains inside the Codespace until the Codespace is deleted. Production
deployment and shared multi-user persistence will be addressed in a later
phase.
